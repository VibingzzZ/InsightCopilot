# InsightCopilot
## 1.项目概述
### 1.1项目名称
知微客服副驾
> 面向美妆电商人工客服的全轨迹服务与风险闭环智能体

### 1.2核心逻辑
围绕人工客服工作场景，构建一个以 Agent 为核心的智能客服副驾，实现：

- 客户信息、聊天、订单、工单等多源数据统一关联
- 自动识别用户意图、情绪、风险及缺失信息
- 基于事实证据生成可编辑、可确认的回复草稿
- 不良反应场景的风险判断、信息收集、工单创建与跟进
- 服务承诺自动提取、时间标准化、履约跟踪与逾期提醒
- 高风险操作支持 Human-in-the-loop
- Agent 关键结论可追溯至聊天、订单、工单及业务规则
- 根据任务复杂度进行 Fast / Reasoning / Vision 模型路由

### 1.3主要流程
```text
消费者发起咨询
    ↓
识别身份、订单和当前诉求
    ↓
整合历史会话、订单与工单
    ↓
判断风险并核验业务事实
    ↓
生成回复建议和下一步动作
    ↓
客服确认后执行
    ↓
自动记录承诺并跟踪履约
    ↓
完成、回访或升级处理
```
