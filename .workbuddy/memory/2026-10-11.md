# 2026-10-11

## 买家消息处理系统新功能（6 项任务全部完成）

在 InsightCopilot 上增量开发「买家消息处理」联调闭环，全部向后兼容，仅新增路由。

新增/改动文件：
- `app/realtime/connection.py`：进程内 `ConnectionManager`（按 session 维护 WS 连接 + broadcast 广播）。
- `app/schemas/commands.py`：`FunctionCommand` 契约 + `parse_command` 解析校验 + `CommandError` 容错（BAD_FORMAT / MISSING_COMMAND / INVALID_COMMAND / EMPTY_DRAFT）。支持 `adjust_tone`(tone∈polite/empathetic/concise/warm)、`optimize_expression`。
- `app/prompt/rewrite.py`：轻量改写 Prompt（低 token，单模板 + goal/extra 插槽）。
- `app/agent/analysis.py` 增加 `RewriteResult`；`app/agent/mock.py` 增加 `mock_rewrite`；`app/agent/rewrite.py`：`rewrite_draft()` 轻量链路，复用 `run_structured`，绕过原副驾重流程。
- `app/main.py`：新增 `WS /ws/{session_id}`（收指令→改写→回写）、`POST /api/test/buyer_message`（跑 run_copilot 后广播）、`CORSMiddleware`（`allow_origins=["*"]`，本地联调用）。`/health` 不变。
- `app/integrations/model/gateway.py`：新增 `_key_usable`，非 ASCII 占位 Key 视为不可用 → 干净降级 Mock（修复此前 UnicodeEncodeError 噪声，恢复 README「无 Key 走 Mock」承诺）。
- `InsightCopilot-frontend/index.html`：自包含联调页（侧边栏按钮 → WS 发 adjust_tone → 渲染真实草稿），无需构建。
- `tests/test_realtime.py`：6 个集成测试覆盖 6 项任务，全过（含跨循环广播、无效指令容错）。
- 同步更新 `README.md` API 表与 WS 协议说明。

验证：57 个测试全过（含原 51）；`uvicorn` 实跑确认 /health、测试接口广播、WS 改写回写、无效指令错误帧均正常。

约定/注意：
- 前端目录此前仅有 `node_modules` 无源码，故联调页用单 HTML（vanilla JS + WS）最简实现。
- CORS 当前全开，仅适合本地联调；上生产应改成白名单。
- **FastAPI 端点命名约定**：路由路径可含 `test/`（如 `/api/test/buyer_message`），但**函数名禁止以 `test_` 开头**（已把原函数 `test_buyer_message` 改名为 `simulate_buyer_message`），否则会被 pytest 当作测试用例收集而报 `fixture 'payload' not found`。跑测试只对 `tests/` 目录运行。
